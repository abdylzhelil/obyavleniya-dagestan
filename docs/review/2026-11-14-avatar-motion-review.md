## Воспроизведение анимации
[Исходная проверка43581959145](https://github.com/abdylzhelil/obyavleniya-dagestan/actions/runs/43581959145):
- Desktop1440:обычныйрежим—радарвращается,ошибокнет.
- Приprefers-reduced-motion:reduce—радарстатичен,кнопкаскрыта,ручногозапусканет.
Настройки конкретного ПК в клубе не известны; системное снижение движения — воспроизведённый сценарий, а не доказанная конфигурация того компьютера.

В подготовленном варианте:
- Системное снижение движения по умолчанию сохраняется.
- Кнопка управления остаётся видимой: «Включить»/«Включить анимацию», затем «Пауза».
- Явное действие разрешает движение только выбранной демонстрации. Остальная страница уважает снижение движения.
- Пауза вне экрана, в скрытой вкладке и ручная пауза сохранены; Space работает.
- ДобавленfallbackстарогометодаmatchMedia.addListener.
- На отдельной странице КлиентРадара декоративная подсветка перекрывала кнопку. Удалён перехват указателя декоративным::before.
- Общее правилоbot.css «выключить все анимации» мешало ручномуopt-in. Добавлены узкие исключения только для движущихся частей радара, без отключения глобальной доступности и без принудительного движения.
- Обновлены версииdemo-motion.css/js и существующая версияbot.css вbot-crm.html, чтобы браузер получил исправления после публикации.
