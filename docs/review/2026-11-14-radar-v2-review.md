# КлиентРадар: переделка анимации, 14 ноября

**Источник:** владелец сообщил, что опубликованная анимация не нравится, и попросил сделать красивее и заменить везде.

**Выполнено:** найдены два места — index.html и bot-crm.html; основной шаблон scripts/templates/client-radar.html используется сборщиком. Подготовлен единый новый компонент: тёмная панель, тонкая сетка, плавный 12-секундный луч, согласованная с проходом луча точка и карточка примера заявки. Никаких реальных данных/счётчиков/обещаний результата. Новый CSS изолирован классом kr-demo. Пауза, reduced-motion и остановка вне экрана сохраняются. scripts/sync_radar.py обновляет оба места из шаблона.

**Частично:** код подготовлен локально, patch сохраняется для проверки в runner. В основной сайт не применён. Предыдущая публикация не означает одобрения нового дизайна.

**Следующий шаг:** браузерная проверка обеих страниц при1440/390 и normal/reduced, изображение и автономный HTML-превью; затем просмотр владельцем. По AGENTS.md: «изменения кода основного сайта отправляются в GitHub только после просмотра результата/diff и разрешения владельца». Публикация нового варианта требует просмотра и разрешения владельца.

Реклама, бюджет, тексты предложения, ссылки групп и цели аналитики не меняются. QA блокирует Метрику. Временный push только для проверки, после результата удалить.
