## Результаты общего аудита

Проверены все 16 HTML-файлов (включая файл подтверждения Яндекса), 19 пользовательских страниц/состояний на 320, 390 и 1280 px — 57 проходов. Проверены 11 уникальных внешних ссылок без повторов сообщений WhatsApp: HTTP 200. Не обнаружены пропавшие локальные ресурсы, битые внутренние цели, горизонтальное переполнение и ошибки JavaScript в проверенных сценариях. Меню, вкладки Modexa и запуск одного видео каждой страницы бота работают.

Подтверждённые оставшиеся вопросы:

1. На основном домене 14 основных страниц всё ещё используют прежний запуск Метрики до согласия. Исправление пока только в подготовленной версии.
2. SEO страниц групп зависит от JavaScript: заголовки, canonical и robots меняются в браузере. Желательны статически генерируемые страницы.
3. Согласие cookie хранит yes/no без версии текста и даты. Желательно версионирование.
4. Реальные цены, оплата и прохождение сценариев внутри ботов НЕ проверены. Нет авторизованной Telegram-сессии. HTTP 200 не равен проверке заказа.
5. Google Fonts запрашивается до согласия на аналитику; это раскрыто в политике. Можно перенести шрифты локально.
6. Внизу рекламы после FAQ можно повторить кнопки заказа.
7. В закрытой копии noindex добавлен в dist, но JavaScript главной и открытых групп может заменить его на index. Сейчас копию защищают авторизация (без входа HTTP 401) и robots.txt с Disallow. Лучше исправить перезапись для режима просмотра.

Не проводились полный WCAG-аудит, юридическая экспертиза, тестирование Safari на физическом iPhone, измерение Core Web Vitals и проверка реальных поисковых позиций. Не утверждать, что эти проверки пройдены.
