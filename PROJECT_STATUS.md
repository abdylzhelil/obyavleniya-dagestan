## Следующее решение: прямой API Директа вместо TinyFish

По просьбе владельца исследован способ самостоятельной настройки. Выбран путь официального API: ЕПК, группы и объявления поддерживаются v501; сетевой вызов campaigns.get без токена получил штатную ошибку 8000 «OAuth-токен не указан» при работающем HTTPS. Соглашения/заявки/новые OAuth-приложения в этом исследовании не создавались, токены не генерировались и не читались.

Для подключения требуется зарегистрировать приложение, оформить доступ API (срок рассмотрения по справке до 7 дней), получить OAuth через Яндекс ID и настроить закрытое хранение секрета. Затем проверить campaigns.get на существующей 715775801, реализовать клиент с проверкой изменений и запретом запуска/роста бюджета без разрешения. Нельзя пока обещать, что автоматическое управление уже работает. [Проверки, ссылки и порядок подключения](docs/marketing/2026-11-03-yandex-api-access.md).

Других подходящих готовых подключений в поиске не найдено. В окружении есть Chromium/Playwright, но прямой браузер упёрся в ошибку сертификата прокси; HTTPS не отключали, вход не выполняли, cookies не переносили, тестовый браузер остановлен.
