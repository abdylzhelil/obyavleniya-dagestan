# ОБЪЯВЛЕНИЯ ДАГЕСТАНА — сайт

Статический сайт-посадочная для групп «ОБЪЯВЛЕНИЯ ДАГЕСТАНА» в WhatsApp и Telegram.
Технологии: HTML, CSS и немного JavaScript. Без сборки, фреймворков, базы данных и серверной части.

## Как посмотреть сайт на компьютере

Откройте терминал в папке проекта и запустите:

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Через двойной клик по `index.html` иконки не покажутся:
браузеры не загружают внешний `sprite.svg` при открытии файла с диска. На хостинге всё работает.

| Часы работы группы (08:00–22:00) | `script.js` (`RULES`, описание группы WhatsApp №1) и `index.html` (JSON-LD, «Почему», «О проекте», FAQ) — менять во всех местах |
| Цвета, шрифты, отступы | `style.css`, переменные в начале файла (`:root`) |
| Страницы ботов (тексты, тарифы, вопросы, скриншоты) | `bot-moderation.html`, `bot-crm.html` — обычный HTML, правится прямо в файле; оформление в `bot.css` |
| Цены тарифов КлиентРадар и пометка «оплата скоро» | `bot-crm.html`, раздел «Тарифы» (карточки `tariff` и серая кнопка `btn-soon`); когда оплата заработает, замените её на ссылку на бота |

| Ссылка «Заказать рекламу» | `reklama.html`, ссылка вида `https://t.me/ModexaGuardBot?start=ad_1` (её показывает бот: «💰 Реклама») |

Ссылки на группы и контакты в HTML не пишутся: кнопки получают адреса из `script.js`.

## Как закрыть заполненную группу и открыть новую

1. В `script.js` у заполненной группы поставьте `status: "full"`.
2. Добавьте новую группу в `GROUPS` со `status: "open"` и её ссылкой. Для WhatsApp задайте следующий `number` и `shortText`.
3. Обновите `sitemap.xml` вручную: уберите страницу заполненной группы и добавьте страницу новой (`group.html?id=<id>`). Файл статический и сам не обновляется.
4. Если в тексте `index.html` где-то прямо названа «вторая группа» или «первая группа», проверьте эти места. Подпись над карточками и ответ в FAQ собираются из данных автоматически.
5. Откройте главную и страницу `group.html?id=<id>` каждой группы и проверьте кнопки.

Что произойдёт само: кнопки вступления в первом экране и подвале поведут в новую открытую группу; заполненная группа получит `noindex` и исчезнет из раздела «Наши группы»; в её карточке появится кнопка перехода в открытую группу; подпись над WhatsApp-карточками и ответ в FAQ (в том числе в JSON-LD) обновятся.

## Адрес сайта

Сайт публикуется по адресу `https://obyavleniya-dagestan.ru`. Адрес записан в файлах: `index.html` (canonical, Open Graph, JSON-LD), `group.html` (картинка Open Graph), `script.js` (`SITE.baseUrl`), `sitemap.xml` и `robots.txt` (строка `Sitemap:`).

Если когда-нибудь понадобится сменить домен, замените `https://obyavleniya-dagestan.ru` на новый адрес (без слэша в конце) во всех этих файлах. В редакторе для этого есть «Найти и заменить во всех файлах» (в VS Code Ctrl+Shift+H; файл `README.md` можно не трогать). После замены проверьте поиском, что старый адрес нигде не остался, и откройте главную страницу: в исходном коде (Ctrl+U) `canonical`, `og:url` и `og:image` должны содержать новый адрес.

## Публикация (GitHub Pages)

Сайт уже опубликован на GitHub Pages: репозиторий `abdylzhelil/obyavleniya-dagestan`, ветка `main`, корень проекта. Любое изменение, попавшее в `main`, появляется на сайте примерно через 1–10 минут (GitHub Pages и браузеры кэшируют файлы). Сборка не нужна. Инструкция ниже нужна, если сайт придётся поднять заново.

1. **GitHub.** Создайте репозиторий и отправьте в него проект. Через сайт github.com это делается кнопкой «Add file → Upload files» (загружаются файлы из этой папки, сама папка не нужна). Через терминал:
   ```
   git init
   git add .
   git commit -m "Сайт ОБЪЯВЛЕНИЯ ДАГЕСТАНА"
   git branch -M main
   git remote add origin <адрес вашего репозитория>
   git push -u origin main
   ```
2. **Включить Pages.** В репозитории: Settings → Pages → Build and deployment → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
3. **Домен .ru.** В файле `CNAME` записан домен (`obyavleniya-dagestan.ru`). У регистратора создайте DNS-записи для основного домена: четыре записи `A` на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; для `www` — запись `CNAME` на `<ваш-логин-github>.github.io`. В Settings → Pages впишите домен в поле Custom domain и дождитесь проверки DNS.
4. **HTTPS.** После проверки домена в Settings → Pages включите «Enforce HTTPS» (сертификат выдаётся автоматически, на это может уйти до часа).
5. **Адрес без `.html`.** GitHub Pages открывает и `/group.html`, и `/group`, но canonical на страницах указывает на адрес с `.html`; ссылки на сайте тоже пишутся с `.html`. Так и оставьте.
6. **Яндекс Вебмастер и Google Search Console.** Добавьте сайт, подтвердите права (файл `yandex_….html` в корне уже есть), отправьте `https://obyavleniya-dagestan.ru/sitemap.xml`.
7. **Яндекс Метрика.** Счётчик 113403438 подключён (код в `<head>` страниц, `SITE.metrikaId` в `script.js`). В интерфейсе Метрики создайте цели типа «JavaScript-событие» с идентификаторами: `join_whatsapp`, `join_telegram`, `ad_contact_telegram`, `ad_contact_whatsapp`, `open_group_page`, `bot_moderation_open`, `bot_crm_open`, `home_bot_moderation`, `home_bot_crm`, `ad_order`, `ad_prices`. Вебвизор и карта кликов выключены.
8. **Яндекс Директ.** Посадочная страница — `index.html`.

### Автообновление числа участников

Файл `data/stats.json` обновляет GitHub Actions (`.github/workflows/update-stats.yml`) раз в 6 часов: скрипт `scripts/update_stats.py` читает число участников с публичной страницы `t.me/AvitoDag05_reklama_group` (токены и ключи не нужны) и, если число изменилось, сохраняет его в `main`. Число показывается на странице `reklama.html`. Запустить вручную: вкладка Actions → «Обновление числа участников» → Run workflow. Если Telegram изменит страницу и скрипт перестанет находить число, на сайте число просто не покажется, а в Actions будет красная отметка.

Метрика собирает данные о посетителях и использует cookie. В проект добавлены политика конфиденциальности (`privacy.html`, ссылка в подвале; в ней есть раздел о боте КлиентРадар) и уведомление о cookie с кнопками «Принять» и «Отказаться» (отказ отключает счётчик). Тексты типовые и юристом не проверялись; если появится возможность, покажите их юристу. Также уточните, нужно ли подавать уведомление об обработке данных в Роскомнадзор.

## Проверка после публикации

- Главная открывается, мобильное меню работает, кнопки ведут в нужные группы.
- `…/group.html?id=telegram-main` и `…/group.html?id=whatsapp-2` открываются; `…/group.html?id=nope` показывает «Группа не найдена».
- `…/robots.txt`, `…/sitemap.xml`, `…/favicon.svg`, `…/assets/images/og-image-v2.jpg` отдаются без ошибок.
- Несуществующий адрес показывает `404.html`.
- Открываются страницы ботов (`bot-moderation.html`, `bot-crm.html`), категории (например, `avto-dagestan.html`) и `reklama.html`; на `reklama.html` видно число участников.
- Переходы между страницами плавные, мобильное меню прокручивается, выпадающие «Категории» и «Боты» работают.
- В Actions последний запуск «Обновление числа участников» зелёный.
- В исходном коде главной (Ctrl+U) видны canonical, Open Graph и JSON-LD с вашим адресом.
- Структурированные данные главной можно проверить в валидаторе микроразметки Яндекса или Google.

## Известные ограничения

- `sitemap.xml` статический: при смене статуса группы или добавлении новой страницы его нужно обновлять вручную.
- Цены и условия в тексте страниц ботов и `reklama.html` записаны вручную; при изменении в боте поправьте и сайт.
- Блоки на страницах ботов появляются с анимацией только при работающем JavaScript (класс `js` на `<html>`); при `prefers-reduced-motion` анимации отключены.
- У `group.html` один файл на все группы. Название, описание, `robots`, canonical и `og:url` конкретной группы выставляет `script.js`. Роботы без JavaScript увидят общий заголовок страницы.
- Шрифты подключаются с Google Fonts. Скорость загрузки в России нужно проверить на реальных устройствах; при необходимости шрифты можно разместить на своём хостинге.
- Если `script.js` не загрузится, блоки с анимацией появления останутся невидимыми (класс `js` ставится на `<html>` до загрузки скрипта).
- Для favicon есть только `favicon.svg`. Отдельных `.ico` и иконки для iOS (apple-touch-icon) нет.
- Контраст текста приведён к WCAG AA (не ниже 4,5:1): на кнопках WhatsApp и Telegram тёмный текст на фирменных цветах, серые тексты светлее прежних. Цвета задаются в `style.css` (`--wa`, `--tg`, `--ink-soft`, `--ink-faint`, `.btn-wa`, `.btn-tg`).
